# ForgeGraph AI

This project is an attempt to explore how useful information can be extracted from industrial maintenance records and connected in a knowledge graph.

The idea is to start with machine learning for information extraction, then gradually explore ways to search and answer questions using the extracted information.

## Current Status

Early stage — setting up the project and reviewing datasets. No model has been trained yet.

## Plan

1. Find and understand a maintenance-text dataset.
2. Explore and clean the data.
3. Train a baseline model for entity extraction.
4. Evaluate its results and identify errors.
5. Explore relationships between entities and build a small knowledge graph.
6. Try answering questions using information from the graph.

I will update the repository as the experiments progress.
